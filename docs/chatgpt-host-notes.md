# ChatGPT ホストの実測メモ

ChatGPT（Plus、Web）に本サーバーをカスタムコネクタとして接続し、ウィジェットの寸法とライフサイクルを実測した記録です。計測日 20260803。

計測手段は2つです。`show_viz` の `height` 引数（px、実測用）と、ウィジェット内の診断オーバーレイ（viewport・`window.openai` のサイズシグナル・fullscreen 要求ボタン）。オーバーレイは `/widget?debug` でのみ有効になります。

ここに書いたのは**未レビューの開発者モードコネクタ**での挙動です。セキュリティレビュー通過後（CSP 強制下）に同じ結果になるかは未検証です。

数値はいずれも計測日時点のものです。ホスト側の UI 実装は予告なく変わるため、値そのものより「どの寸法がホストに握られていて、どれが自分で決められるか」の切り分けとして読んでください。実際、幅は 20260804 の再確認で 20260803 と異なる挙動を示しました（下記）。

---

## サイズ

インラインカードのウィジェット幅はホストが決めます。ここは自分で決められない側です。

20260803 の計測では **~768px で一定**でした。ブラウザ窓幅を変えても変わらず、会話カラム幅に張り付きます。

20260804 に同じコネクタで再確認したところ、**この値は再現しませんでした**。会話をリロードした後、カードがより広く描画され、ダッシュボードのフィルターが右カラムへ再配置されています。何が幅を変えたかは特定できていません（リロードの有無・ホスト UI の更新・会話レイアウトの差、いずれも切り分け未了）。

したがって固定値を前提に設計しないでください。後述の設計目安（幅 750px 以下）は、狭い側に倒しておけばどちらでも破綻しない、という趣旨です。

カードの高さは**ウィジェットのコンテンツ高に 1:1 で追従**します。既定 480px は「コンテンツが `100vh` で枠を埋める」場合の平衡値にすぎません。コンテンツを 1200px / 3000px にすると、カードもそのまま 1200 / 3000px になりました（上限は未到達）。

`window.openai` には `notifyIntrinsicHeight` / `notifyIntrinsicWidth` / `requestDisplayMode` があります。`maxHeight` / `maxWidth` キーは存在しますが、inline 表示時は未配信（undefined）でした。

`requestDisplayMode({mode:"fullscreen"})` は許可され、viewport は 767×480 → 1354×934 に拡大しました。ただし固定サイズのダッシュボードは fullscreen でも元サイズのままで、余白が広がるだけです。

この実測から、ダッシュボード設計の目安は幅 750px 以下（固定または「自動」サイズ）になります。

## キャッシュとライフサイクル

ChatGPT はツール定義（スキーマ）もウィジェット HTML（リソース）も**コネクタ登録時にキャッシュ**し、再接続では更新しません。サーバー側の変更を反映するには、コネクタ詳細（開発者モード）の「情報」セクションにある「更新する」ボタンで再取得します。

ページリロード時、ChatGPT はツール結果（`toolOutput`）をウィジェットへ**再配信しません**。そのためリロード後の表示復元は、`setWidgetState` に保存した `restore` ブロック（viz URL・高さ）をウィジェット自身が読み戻すことで行っています。

20260804 に実地で確認しました。リロード後、viz は復元されて描画されます。一方フィルターは初期値に戻りました。`restore` が保存するのは viz URL と高さだけなので、想定どおりの挙動です。viz の操作状態まで復元したい場合は、`restore` に載せる情報を増やす必要があります。

## 高さの決定ロジック

上記の実測を受けて、ウィジェットは次の優先順で高さを決めます。

1. `height` 引数の明示指定
2. ダッシュボードの公開サイズからの自動計算（exactly / range の公開高さ + ツールバー 35px、480〜1200 にクランプ）
3. 既定（ホスト枠 = ChatGPT では 480px）

「自動」サイズのダッシュボードは、3 の既定高さに自身が追従します。

Embedding API の内部 iframe は viewport 基準で作られるため、ウィジェットは shadow DOM 経由でその高さを wrap の高さに強制同期しています。

## メタデータの2方言

サーバーは同じ内容を2つの方言で併記しています。これにより、Claude 系ホストと ChatGPT の両方で同じサーバーがそのまま動きます。

| 用途 | 標準（SEP-1865） | OpenAI legacy |
|---|---|---|
| ウィジェット resource の指定 | `_meta.ui.resourceUri` | `openai/outputTemplate` |
| frame ドメインの宣言 | `_meta.ui.csp.frameDomains` | `openai/widgetCSP.frame_domains` |

OpenAI の公式ドキュメントは現在、標準の `_meta.ui.*` を推奨形式、`openai/*` を legacy 扱いとしています。ただし legacy 側を落として安全かは未検証のため、両方を出しています。

mimeType は SEP-1865 の `text/html;profile=mcp-app` のままで描画されました（`text/html+skybridge` への変更は不要でした）。
